## 🛠️ How to Edit in Adobe Illustrator (`.ai`) & Figma

1. **Adobe Illustrator:**
   - Double-click any `.svg` file or choose **File ➔ Open...** in Adobe Illustrator.
   - All vector paths, curves, strokes, gradients, and anchor points will load as native editable layers.
   - To save as a native `.ai` project: Go to **File ➔ Save As...** and select **Adobe Illustrator (*.ai)**.
2. **Figma / Canva:**
   - Simply drag and drop any `.svg` directly onto your Figma canvas. Every vector node is individually editable.
3. **CapCut / Premiere Pro / DaVinci Resolve (Video Watermark):**
   - Import `01-icon-only-transparent/utilby-icon-dark-2048.png` or `utilby-icon-white-2048.png`.
   - Place it on the top video track, adjust scale to ~8–12%, and position in the top-right or bottom-right corner.
   - Adjust opacity to 70–85% for a subtle watermark.
